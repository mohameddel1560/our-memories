# Our Memories

A private romantic memories website for two people, built with React and Vite.

## Live site

https://mohameddel1560.github.io/our-memories/

## Included

- Ukrainian-first interface with Arabic language toggle
- Local browser storage for memories, photos, notes, and dates
- Emoji username/password access gate
- ZIP download in public/our-memories-site.zip

The memories and photos are stored locally in each browser. They are not synchronized between devices.
